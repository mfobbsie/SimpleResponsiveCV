Introduction
Simple Responsive CV is a personal webpage designed to highlight my education, experience, and skillset. It also provides background information about me for potential employers exploring my work.

This project was built using HTML for structure and CSS for styling. One of the main challenges was aligning the profile image to the left of the text while maintaining a clean, responsive layout. Another tricky part was adjusting the text so it remained readable across the light and dark areas of the background image.

As I continue developing my portfolio, I plan to enhance this page with screenshots, .gifs, or links to the projects referenced. I also hope to refine the visual style so it better reflects my personal aesthetic.

Features
Clean, responsive CV layout

Profile image with accompanying introduction

Sections for education, experience, and skills

Background image with readable text overlay

Beginner‑friendly HTML/CSS structure

Prerequisites
Before installing or running this project, ensure you have:

Git

Node.js and npm

A code editor such as VS Code

A modern web browser

Installation
To access and run this project locally, follow these steps in your terminal:

bash

# 1. Clone the repository

git clone https://github.com/mfobbsie/SimpleResponsiveCV

# 2. Navigate into the project directory

cd SimpleResponsiveCV

# 3. Install dependencies

npm install

# 4. Start the development server

npm start
Usage
Once the development server is running, open your browser and navigate to:

Code
http://localhost:3000
From there, you can explore the CV layout, review the structure, and customize the content to reflect your evolving professional story.
